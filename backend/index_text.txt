58: &nbsp; Functional Requirements
59: FR • 01—08
60: 01
61: Accept IaC templates in .tf, .json,
62: .yaml and .yml formats and initialize
63: AgentShield execution state.
64: 02
65: Parse Terraform, CloudFormation,
66: Kubernetes and Helm templates into
67: structured ASTs and resource graphs.
68: 03
69: Detect exposed credentials, tokens
70: and private keys using Gitleaks,
71: TruffleHog and entropy detection.
72: 04
73: Retrieve relevant CIS, NIST, CVE and
74: cloud security policies through
75: vector-based RAG.
76: 05
77: Perform multi-LLM vulnerability
78: verification using Claude 3.5 Sonnet
79: and GPT-4o ensemble voting.
80: 06
81: Generate syntactically correct unified
82: Git diff patches for vulnerable
83: resource blocks.
84: 07
85: Validate generated patches using
86: static linters and LocalStack
87: sandbox execution.
88: 08
89: Generate compliance reports and capture
90: developer ACCEPT / REJECT / MODIFY
91: feedback.
