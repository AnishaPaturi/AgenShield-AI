LITERATURE SURVEY

1. OVERVIEW & CATEGORIZATION OF EXISTING APPROACHES
--------------------------------------------------
Infrastructure-as-Code (IaC) security research spans static analysis, dynamic monitoring, machine learning, and recent Large Language Model (LLM) workflows.

1. Static Analysis & Rule-Based Scanners (CDK-Nag, Checkov, KICS):
   - Mechanism: Parses IaC code against rigid rule packs.
   - Limitation: Misses complex, context-dependent misconfigurations (e.g., compound IAM policy risks) and generates high false-positive rates with parameterized code.

2. Dynamic Analysis & CSPM (AWS Config, Cloud Posture Tools):
   - Mechanism: Monitors live cloud resources post-deployment.
   - Limitation: Reactive ("shift-right"); fails to catch vulnerabilities before code is deployed.

3. ML-Based Security Smell Detectors (GLITCH - Saavedra & Ferreira, 2022):
   - Mechanism: Uses machine learning on intermediate representations across IaC languages.
   - Limitation: Requires massive labeled datasets, fails on zero-day patterns, and lacks remediation generation.

4. LLM & Early Agentic Workflows (Base Paper - Toprani & Madisetti, 2025; GenKubeSec - Malul et al., 2024):
   - Mechanism: Uses LLMs + RAG to detect context-aware vulnerabilities in AWS CloudFormation.
   - Limitation: Single-cloud scope, single-LLM hallucination risks, ~15% false-positive rate, text-only advice (no code diff patches), and minimal dataset evaluation.

3. KEY RESEARCH GAPS & AGENTSHIELD AI POSITIONING
--------------------------------------------------
1. Cloud Scope:
   - Base Paper Limitation: Restricted to AWS CloudFormation.
   - AgentShield AI Solution: Multi-cloud support for AWS, Azure, GCP across Terraform, CFN, K8s, and Helm.

2. Remediation:
   - Base Paper Limitation: Text-only recommendations.
   - AgentShield AI Solution: Automated generation of syntactically correct diff patches with LocalStack sandbox testing.

3. Reliability:
   - Base Paper Limitation: Single-LLM risks hallucinations & ~15% false positives.
   - AgentShield AI Solution: Multi-LLM ensemble voting (Claude + GPT-4o) with confidence scoring & human escalation.

4. Secrets Leakage:
   - Base Paper Limitation: Completely ignores hardcoded credentials.
   - AgentShield AI Solution: Dedicated Secrets Scanner Agent integrating Gitleaks and TruffleHog engines.

5. Compliance:
   - Base Paper Limitation: Generic best-practice advice.
   - AgentShield AI Solution: Automated compliance mapping to SOC 2, HIPAA, PCI-DSS, and NIST 800-53.
