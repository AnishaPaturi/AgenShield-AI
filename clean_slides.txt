ABSTRACT

The proposed system introduces an Al-driven multi-agent security framework that combines

Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to intelligently
analyze Infrastructure-as-Code (laC) templates. A continuously updated cloud security

knowledge base stores best practices and compliance standards to enhance detection accuracy.

Unlike traditional static analysis tools, the framework performs context-aware security
analysis to identify complex cloud misconfigurations that depend on resource relationships

and deployment context. It achieves an 85% detection rate with approximately 15% false

positives, while providing natural-language remediation guidance integrated directly into
CI/CD pipelines for automated secure deployments.

The current evaluation is limited to AWS CloudFormation templates across
10 sample configurations, demonstrating the effectiveness of Al-assisted cloud security

analysis while highlighting opportunities for broader multi-cloud support.
