Base Paper

Core Objective

  • AI-driven pre-deployment IaC security workflow.
  • Combines LLMs + RAG for context-aware vulnerability detection.
  • Overcomes limitations of rule-based static scanners.
  • Generates natural-language remediation guidance.

Proposed Pipeline

  1. RAG Retrieval → AWS Docs & CIS Benchmarks
  2. Claude 3.5 Sonnet → Vulnerability Detection
  3. Report Generator → Markdown Security Report

Results

  • Recall : 85%
  • Precision : 85%
  • F1 Score : 85%
  • Avg Scan : 85 sec

Strengths

  • Context-aware detection
  • Reduced hallucinations
  • Dynamic knowledge updates
  • Developer-friendly reports

Limitations

  • AWS CloudFormation only.
  • No Terraform / Azure / GCP support.
  • No automated patch generation.
  • No secrets scanning.
  • No sandbox validation.
