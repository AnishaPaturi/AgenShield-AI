Functional & Technical Specification

AgentShield AI — requirements, quality attributes and deployment environment

AGENTIC DEVSECOPS

  Functional Requirements

FR • 01—08
01

Accept IaC templates in .tf, .json, .yaml and .yml formats and initialize AgentShield execution state.

02

Parse Terraform, CloudFormation, Kubernetes and Helm templates into structured ASTs and resource graphs.

03

Detect exposed credentials, tokens and private keys using Gitleaks, TruffleHog and entropy detection.

04

Retrieve relevant CIS, NIST, CVE and cloud security policies through vector-based RAG.

05

Perform multi-LLM vulnerability verification using Claude 3.5 Sonnet and GPT-4o ensemble voting.

06

Generate syntactically correct unified Git diff patches for vulnerable resource blocks.

07

Validate generated patches using static linters and LocalStack sandbox execution.

08

Generate compliance reports and capture developer ACCEPT / REJECT / MODIFY feedback.
