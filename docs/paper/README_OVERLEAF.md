# AgentShield AI - Springer Conference Proceedings (Overleaf Package)

This package is prepared directly according to the official Springer Conference Proceedings Template:
https://www.overleaf.com/latex/templates/springer-conference-proceedings-template-updated-2022-01-12/wcvbtmwtykqj

## How to Upload and Use on Overleaf:
1. Go to https://www.overleaf.com/project
2. Click on **'New Project'** -> **'Upload Project'**.
3. Select this ZIP file: AgentShield_AI_Overleaf_Springer_Package.zip.
4. Overleaf will automatically unpack all files and set samplepaper.tex as the main document.
5. Click **'Recompile'**. It will compile cleanly using pdfLaTeX.

## Files Included:
- samplepaper.tex: Main Springer LNCS document with all 9 sections, equations, tables, case study listings, and 27 references.
- llncs.cls: Official Springer LNCS LaTeX class.
- splncs04.bst: Official Springer LNCS BibTeX bibliography style.
- samplepaper.pdf: Pre-compiled reference 16-page PDF.
- paper_figures/: All 5 high-resolution architectural, benchmark, and empirical figures.
